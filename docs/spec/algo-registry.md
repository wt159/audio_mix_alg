## 1. 登记表结构

每算法一节，字段固定：

- **名称**：登记名（CLI 表格与 WAV 文件名使用）
- **类型**：逐样本公式 / 动态链路
- **公式出处**：精确到条款/公式号的一手来源
- **生态位**：一句话——相对现有五算法补了什么
- **ctx 约定**：无状态=空置；有状态=结构名 + 统计字段 + 双音测试复用语义（统计须在双音测试**前**存入）
- **参数默认值**：全部可调参数及默认值
- **指标实测**：resid_db / resid_shape / 钳位与增益统计 / 峰值 / RMS / 波峰因数 / **dBTP**
- **听感条款**：A-B 盲听 vs 线性硬饱和基准，判据"不劣于"（首批免执行，此列占位）
- **验收状态**：PASS / FAIL / 免执行

## 2. 指标门槛数值判据

### 2.1 通用（全部新算法）

- `make` 零警告（`-Wall -Wextra -pedantic`）。
- debug 构建（ASan/UBSan）干净跑完 `--sec 1` 与 WAV 输入路径冒烟。
- 指标行无 NaN/inf；`-inf` 残差 = 完全线性，属正常。
- float 域输出 `|peak| ≤ 1.0`。

### 2.2 E 真峰值前瞻限幅（ITU-R BS.1770-4 Annex 2 + EBU R128 §m）

- 检测链：4× 过采样、48 阶 4 相位 FIR，系数表以 BS.1770-4 Annex 2 逐字核对。
- ceiling = −1.0 dBTP；**门槛 = 节目输出实测 dBTP ≤ −0.7 dB**（−1.0 上限 + R128 ±0.3 dB 容差）。
- 实现复用检测 FIR 为指标列：对全部算法输出计算 dBTP（新增指标列，见 §4）。
- 实现状态（2025 E 首批）：`src/truepeak.{c,h}`，登记名 `truepeak 前瞻限幅`（`09_truepeak.wav`，链路 [9]），Makefile SRCS 已登记。系数表含 22 个负系数（从 ITU PDF 逐字录入，pdfminer 提取核对 + broadcast-loudness 交叉验证）；检测链 float 域省略 12.04 dB 预衰减（Annex 2 §3 明示可省）。实测（合成 1 s，`--no-match`）：节目输出 dBTP = −1.0 dB ≤ −0.7，安全钳位 1；门槛 PASS（听感条款免执行）。注：满幅正弦峰在采样点上时 dBTP ≈ 0（滤波器增益归一），方波 1 kHz 实测 +2.0 dB ≈ 4/π 重建峰（理想 sinc +2.10 dB，48 阶 FIR 限带略低）——“满幅正弦 ≈ +3.01 dB”的校验点与标准行为不符，未采用（见 ADR-0003）。

### 2.3 D 软拐点压缩器（Giannoulis/Massberg/Reiss JAES 2012）

- 增益计算机 §2.2 Eq(4)（软拐点抛物线），分支峰值检测 §2.3.3 Eq(15)。
- 默认参数：T = −18 dBFS（对齐仓库响度锚点）、R = 4:1、W = 6 dB、attack 10 ms、release 100 ms。
- **门槛**：增益只衰减不放大；输出样本峰 ≤ 0 dBFS。
- 实现状态（2025 D 首批）：`src/comp_soft.{c,h}`，登记名 `softknee`，Makefile SRCS 已登记。检测器按论文 §2.4.1 Eq(20) 推荐放线性域（dB 变换前）；T 语义为叠加信号 dBFS 域，无检测域缩放。Eq(15) 释放支路为纯放电 `αR·yL[n−1]`（Eq(16) 是带 (1−αR)·xL 项的变体，未用）。实测（合成 1 s）：增益只衰减，最小增益 −11.6 dB，样本峰 −7.2 dBFS ≤ 0，安全钳位 0；门槛 PASS（听感条款免执行）。

### 2.4 A 三次软削波（JOS PASP §9.1.6）

- 三分段公式：`|x|≤1` 时 `f(x)=x−x³/3`；`|x|>1` 时钳到 `±2/3`（曲线端点值）。±1 处斜率为 0（C0 饱和；tanh 实现是 C1，谱形与接点连续性可对比）。
- **带宽扩展因子 = 3** 写入文档；钳位统计语义与 tanh 一致（统计 |x|>1 的样本，返回钳位样本数）。

### 2.6 L 放大族对照（μ/A 律，ADR-0004 裁定二）

- 结构判据（采样验证）：曲线在全输入域单调、有界（|y|≤1）、过端点 (0,0)/(1,1)。
- 放大特性：小信号实测原点斜率 μ 律 46.0（+33.25 dB）/ A 律 16.0（+24.1 dB），与理论值偏差 ≤5%；全表唯一破「不放大」不变量的族，登记价值在测量对照（检验响度对齐框架对放大族的公平性）。
- 越界输入：线性相加 |x|>1 时，输入钳位到 ±1 再过曲线，计入钳位统计（与 tanh 平台段计数语义同构）。
- 引用措辞：「ITU-T STL-2000 手册 g711.tex 的连续律公式 + ITU 参数」（μ=255、A=87.6；与手册正文 87.56 并存时注明），不得写「G.711 规定的连续曲线」。

## 2.5 首批门槛跑数实测（#6，`--sec 2 --no-match`，48 kHz 合成）

| 算法 | 门槛 | 实测 | 判定 |
|---|---|---|---|

| softknee 压缩器 | 增益只衰减；样本峰 ≤ 0 dBFS | 最小增益 −12.0 dB 无放大；样本峰 −5.8 dBFS | PASS |

## 3. 听感门槛条款（首批免执行）

- 流程：A-B 盲听，基准 = 线性硬饱和算法输出（`--no-match` 真实电平）。
- 判据：新算法不劣于基准（人声/音乐节目素材各一段）。
- 首批状态列填"免执行"；执行另起 effort。
- L 放大族（μ/A 律）：对照族——免执行，价值在指标对照不在听感（ADR-0004 裁定二；登记表条目措辞随此）。

## 4. dBTP 指标列

- 指标表新增 dBTP 列，对**全部**算法（含现有五算法与参考链路）的节目输出计算。
- 计算复用 E 的 4× FIR 检测链（BS.1770-4 Annex 2 规定的过采样峰值 + 20·log10 取 dBTP）。
- 验证基准：欠读公式 0.688 dB @4×/fnorm=0.5（BS.1770-4 Appendix 1 to Annex 2）。

## 5. 验收标准（每个新算法）

1. `src/mix_algos.c`（或新模块，新 `.c` 登记 Makefile `SRCS`）+ 头文件声明。
2. `main()` `algos[]` 登记 + `nalgo` 与数组容量同步。
3. README 算法表同步。
4. §2.1 通用门槛 + 本算法专属门槛全部 PASS。
5. 新术语进 `GLOSSARY.md`（仅领域概念，不含实现细节）。
6. 难逆且费解的决策记 ADR（`docs/adr/`，编号递增）。

### 6.1 线性相加 + 硬饱和

- **名称**：`线性相加 + 饱和`（CLI 表格名；`01_sum_clip.wav`）
- **类型**：逐样本公式
- **公式出处**：本仓库既有（无文献公式；int16 相加 + INT16_MIN/MAX 饱和）

- **验收状态**：已收录

### 6.2 平均 (a+b)/2

- **名称**：`平均 1/2`（`02_average.wav`）

- **验收状态**：已收录

### 6.3 防削波 a+b−ab/M

- **名称**：`防削波 a+b-ab/M`（`03_noclip.wav`）

- **听感条款**：基准族
- **验收状态**：已收录

### 6.4 contra (a²+b²)/(a+b)

- **名称**：`contra (a^2+b^2)/(a+b)`（`04_contra.wav`）
- **类型**：逐样本公式

- **听感条款**：基准族
- **验收状态**：已收录

### 6.5 float + 前瞻限幅

- **名称**：`float + 前瞻限幅`（`07_float_limiter.wav`）
- **类型**：动态链路
- **公式出处**：本仓库既有（`src/limiter.c`：环形延迟线 + 窗口峰值 + 一阶起控/释放平滑；README「推荐做法」）
- **生态位**：推荐基准——把「防削波」从逐样本公式移到带时间常数的动态处理，保护采样点峰值
- **ctx 约定**：有状态。`limiter_cfg_t`；统计字段 `active_samples` / `hard_clips` / `gain_sum`（已除样本数）/ `gain_min`；节目统计须在双音测试**前**由 `main()` 存走（双音复用会覆盖）

- **指标实测**（48 kHz / `--sec 2 --no-match`）：峰值 −1.0 dBFS；RMS −12.1 dBFS；波峰因数 11.1；钳位 8（安全钳位）；dBTP −1.0 dB；波形残差 −38.3 dB；互调残差 −80.8 dB；增益统计：平均 −0.3 dB / 最小 −2.5 dB
- **听感条款**：基准族
- **验收状态**：已收录

### 6.6 tanh 软饱和

- **名称**：`tanh 软饱和`（`05_tanh_sat.wav`）
- **类型**：逐样本公式
- **公式出处**：本仓库既有（三分段：|x|≤0.5 线性、越界后 `0.25+tanh(k(|x|−0.5))/(2k)`，k=0.8，C1 接点；实现注记见 `src/mix_algos.c`）
- **生态位**：奇对称光滑压缩——小信号线性、单调有界（|y|<0.875）、永不硬削波；cubic 的「超越 vs 代数」对照面
- **ctx 约定**：无状态，空置
- **参数默认值**：k = 0.8；接点 ±0.5；平台上界 ≈0.875（−1.2 dBFS）
- **指标实测**（48 kHz / `--sec 2 --no-match`）：峰值 −3.0 dBFS；RMS −11.6 dBFS；波峰因数 8.6；钳位 0；dBTP −3.0 dB；波形残差 −10.7 dB；互调残差 −14.3 dB
- **听感条款**：基准族
- **验收状态**：已收录

### 6.7 三次软削波 x−x³/3（cubic）

- **名称**：`三次软削波 x-x^3/3`（`06_cubic_soft.wav`）
- **类型**：逐样本公式
- **公式出处**：JOS PASP "Cubic Soft Clipper" §9.1.6（`|x|≤1`: f(x)=x−x³/3；端点 f(±1)=±2/3，平台段钳端点值；带宽扩展因子 3）
- **生态位**：代数多项式族——无超越函数（每样本 2 次乘加，仓库最快软饱和），与 tanh 构成「代数 vs 超越」直接 A/B；C0 接点 vs tanh C1 的谱形对照
- **ctx 约定**：无状态，空置（与 tanh 钳位统计语义一致：统计 |x|>1 进平台段的样本数）
- **参数默认值**：无（曲线即参数：线性段 −1≤x≤1，平台 ±2/3，输入域按线性叠加归一到 ±2）
- **指标实测**（48 kHz / `--sec 2 --no-match`）：峰值 −3.5 dBFS；RMS −10.0 dBFS；波峰因数 6.5；钳位 1390（与线性相加同样本集）；dBTP −3.5 dB；波形残差 −18.5 dB；互调残差 −10.0 dB
- **听感条款**：免执行（首批）
- **验收状态**：PASS

### 6.8 软拐点压缩器（softknee）

- **名称**：`softknee 压缩器`（`08_softknee.wav`）
- **类型**：动态链路
- **公式出处**：Giannoulis/Massberg/Reiss，"Digital Dynamic Range Compressor Design—A Tutorial and Analysis"，JAES 60(6), 2012——增益计算机 §2.2 Eq(4)（软拐点抛物线）、分支峰值检测 §2.3.3 Eq(15)（释放支路取纯放电 αR·yL[n−1]，Eq(16) 变体未用）、检测域按 §2.4.1 Eq(20) 放线性域
- **生态位**：调动态而非保峰值——软拐点、慢起释、无前瞻，与限幅器（硬拐点、快速、前瞻）同属动态链路可公平对照；在仓库慢变增益剥离残差指标下与限幅器分工清晰
- **ctx 约定**：有状态。`comp_soft_cfg_t`；统计字段 `active_samples` / `hard_clips` / `gain_sum`（已除样本数）/ `gain_min`；节目统计须在双音测试**前**由 `main()` 存走
- **参数默认值**：T = −18 dBFS（对齐仓库响度锚点）；R = 4:1；W = 6 dB；attack 10 ms；release 100 ms；pregain 1.0
- **指标实测**（48 kHz / `--sec 2 --no-match`）：峰值 −5.8 dBFS；RMS −17.3 dBFS；波峰因数 11.5；钳位 0；dBTP −5.8 dB；波形残差 −34.4 dB；互调残差 −13.7 dB；增益统计：平均 −7.2 dB / 最小 −12.0 dB（只衰减，无放大）
- **听感条款**：免执行（首批）
- **验收状态**：PASS

### 6.9 真峰值前瞻限幅（truepeak）

- **名称**：`truepeak 前瞻限幅`（`09_truepeak.wav`）
- **类型**：动态链路
- **公式出处**：ITU-R BS.1770-4 (10/2015) Annex 2 §3（检测链：4× 过采样 + 48 阶 4 相位 FIR，"order 48, 4-phase, FIR interpolating" 系数表逐字录入；float 域省略 12.04 dB 预衰减，§3 明示可省）+ EBU R128-2023 §m（ceiling 语义：制作阶段节目真峰值 ≤ −1 dBTP）；限幅结构 = `src/limiter.c` 前瞻骨架
- **生态位**：保重建峰而非采样峰——DAC sinc 重建后的样本间峰也不越 ceiling，是唯一以 dBTP 驱动的链路；兼作全部算法的 dBTP 指标列（§4）
- **ctx 约定**：有状态。`truepeak_cfg_t`；统计字段 `active_samples` / `hard_clips` / `gain_sum` / `gain_min`；FIR 历史与限幅器状态不对外暴露；节目统计须在双音测试**前**由 `main()` 存走
