# 0003 — 真峰值检测链：系数表提取方法与 dBTP 校验点的修正

实现 E（真峰值前瞻限幅，BS.1770-4 Annex 2）时有两个从代码不易反推的决策。

**其一，系数表的 22 个负系数不能从"空白格"猜。** Annex 2 §3 的系数表是 12 行 × 4 相位列的网格，PDF 渲染下负号是独立字形（U+2212），且负系数所在格与"值为 0 的格"在外观上都可能呈现为稀疏排版。第一版按坐标重建时把负系数格当成了 0 系数，得到的"滤波器"各相位直流增益为 1.218/1.498——不可能是插值器（合法插值器各相位直流增益 ≈ 1）。用 pdfminer 提取 PDF 文本层后确认：**表里没有 0 系数，26 个正系数 + 22 个负系数 = 48 个全部非零**，负号在文本层以 Unicode 减号呈现。流程定式为：坐标重建网格（防串行）→ pdfminer 文本层逐字核对（防漏负号）→ broadcast-loudness 0.7.0 的 BS.1770-5 同表交叉验证。提取后各相位直流增益 1.0016/0.9730，满幅正弦读数 ≈ 0 dBTP，自洽。

**其二，"满幅正弦 dBTP ≈ +3.01 dB"的校验点是错的，未采用。** 原始校验点把方波的重建峰性质（傅里叶首项 4/π，即 +2.10 dB）记到了正弦头上；+3.01 dB = 20·log10(√2) 是双音叠加的采样峰关系，与真峰值无关。BS.1770-4 Annex 2 的检测链把滤波器增益归一化到 1（"normalises the overall gain of the processing to unity"），因此**满幅正弦峰落在采样点上时 dBTP ≈ 0**，这是标准的正确锚点。实测：997 Hz 满幅正弦（峰对齐采样点）+0.01 dB；1 kHz 满幅方波 +2.00 dB（理想无限带宽 sinc 重建 +2.10 dB，48 阶 FIR 限带后略低，符合滤波器设计）；替代校验点采用方波 4/π 重建峰。

**检测链省略 12.04 dB 预衰减**：Annex 2 §3 原文明示该步"not necessary if the calculations are performed in floating point"，其后 +12.04 dB 补偿同步省略（float 域两步相消）。欠读界 0.688 dB @4×/fnorm=0.5 已由 ceiling −1.0 dBTP（R128 §m）与窗口真峰值驱动的增益共同覆盖：实测节目输出 dBTP = −1.0 dB，在 −0.7 dB 门槛内。
