# 0004 — 对数律语义裁定：放大族对照入册，非软削波

连续 μ 律（μ=255）/A 律（A=87.6）能否进本工具登记表、以什么语义进，由[地图 #8](https://github.com/wt159/audio_mix_alg/issues/8) 的[调研票 #9](https://github.com/wt159/audio_mix_alg/issues/9) 与[裁定票 #10](https://github.com/wt159/audio_mix_alg/issues/10) 裁定。引用措辞自此固定：两律公式指 **ITU-T STL-2000 手册（g711.tex）的连续律公式 + ITU 参数**——G.711 标准本体以判决值表立法、正文无 μ=255/A=87.6 字样、且明言不采用连续形式，故不得写「G.711 规定的连续曲线」。事实底座：`research/g711-log-law-facts` 分支 `docs/research/g711-log-law-facts.md`。

**裁定一：软削波判据收窄为「不放大」。** g(x)=|f(x)|/|x|≤1 对一切 x≠0 是「软削波」的必要条件；原点近透传（g→1）降为渐近性质、非必要条件——tanh 与 cubic 原点只是近透传、并无恒等透传段，雾区旧措辞「原点附近保持线性」若严格解释会误伤自家两条曲线。连续 μ/A 律是端点 (0,0)、(1,1) 的严格凹映射，对 x∈(0,1) 恒有 y>x：全程增益 >1（原点斜率 46.0/16.0，端点 0.180/0.183），无任何阈下透传段，结构性不属软削波。

**裁定二：以「对数域全动态压缩映射（放大族对照）」身份入册。** 它是全表唯一破「不放大」不变量的曲线，登记价值在**测量对照**——检验响度对齐框架（resid_db 吸收整体增益）对放大族是否公平。μ=255 与 A=87.6 **都入册**、互为「放大强度」维度的天然 A/B：原点斜率差 9.2 dB（33.25 vs 24.1），大信号端几乎重合（0.180 vs 0.183）。感知加权语义否决：本工具以对齐度量框架测它，不存在响度加权预处理链路。预缩放条件入册分支被数学排除：预缩放 k 倍再端点归一化后原点增益为 μk/ln(1+μk)，由 ln(1+t)<t（t>0 时严格）知其恒 >1——归一化只能压小放大、不能消除，「不放大」判据仍破。

**裁定三：数值以更正为准。** μ 律原点斜率 μ/ln(1+μ) = 255/ln(256) ≈ **46.0**（33.25 dB）；调研报告 mix-algo-survey.md §1-C 与地图旧文写的 ≈48.9 为笔误。A=87.6 与 STL 手册正文 87.56 两写法并存（87.56 使原点斜率恰为 16.00），引用时注明。压扩源头文献 Holbrook & Dixon 为 1939 年。

**实现不跟随本裁定**：入册 ≠ 现在实现。μ/A 律链路的 C99 实现、algos[] 登记、指标跑数均不在本裁定范围内，另行 effort；届时按登记表 §5 验收标准执行，本 ADR 只锁语义与判据。
