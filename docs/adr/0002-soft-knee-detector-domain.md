# 0002 — 软拐点压缩器：检测器域与 Eq(15) 的精确形态

实现 D（软拐点压缩器，JAES 2012）时有两个从代码不易反推的决策。

**其一，检测器放在线性域（dB 变换之前）。** 论文 §2.4.1 Eq(20) 给出推荐位置：`xL = |x[n]|`，检测器在前、dB 变换在后（`xG = 20·log10(yL)`）。备选是 §2.4.2 的对数域检测（先取 dB 再平滑），两者在稳态等价、在包络动态上不同；选 Eq(20) 位置使阈值 T 的语义直接落在叠加信号的 dBFS 域上，与仓库指标（峰值/RMS dBFS）同域可对照。推论：本链路**没有**限幅器式的 ceiling 缩放，T=-18 dBFS 是字面语义，混入两路 +4 dBFS 素材时增益计算机会深入压缩区工作。

**其二，释放支路用 Eq(15) 而非 Eq(16)。** 论文给了一对容易混淆的分支峰值检测器：Eq(15) 释放支路只对状态放电（`yL = αR·yL[n-1]`），Eq(16) 才是带 `(1-αR)·xL[n]` 项的"连续释放"变体。选 Eq(15)：规格（`docs/spec/algo-registry.md` §2.3）指名 Eq(15)，且其释放时间常数恰为 τR（论文 Fig. 5 的对比结论），参数语义最直白。代价是释放到零后包络静止在 0（静音期检测电平钳在 -180 dB 下限），对增益计算机无影响（xG 低于拐点即单位增益）。

**增益只衰减不放大**是规格门槛：实现上不靠参数假设，而是在样本环内对 `cdB > 0` 硬钳到 0（防御 Eq(4) 抛物线分支外的浮点边界）；统计字段语义沿用 limiter 约定（双音测试前存入节目统计）。
